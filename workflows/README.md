# Workflow exports

These n8n exports have been sanitised for public sharing.

Before importing / running them, configure:

- Microsoft OneDrive / Excel OAuth credentials;
- the OneDrive workbook item ID (`REPLACE_WITH_ONEDRIVE_WORKBOOK_ID`);
- Workflow 03's production Form ID inside Workflow 02 approval URLs;
- Workflow 04's local Python script path; and
- Workflow 05's Microsoft Graph workbook path.

All workflows are exported as inactive to prevent accidental execution after import.
